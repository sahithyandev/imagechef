# Security policy

## Supported versions

Security fixes are made on the latest version of the default branch. This project has not yet published versioned releases.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue. Instead, use GitHub's private security advisory reporting for this repository. If private reporting is unavailable, contact the repository owner through their GitHub profile and include:

- A clear description of the issue and its impact.
- A minimal, safe reproduction or proof of concept.
- The affected commit, browser, and operating system when relevant.
- Any suggested mitigation.

Please avoid accessing data that is not yours, disrupting services, or testing against third-party deployments. We will acknowledge a good-faith report, investigate it, and coordinate disclosure once a fix is available.

## Scope notes

imagechef is a static, browser-first application. It does not include an application API, authentication system, or server-side image processing. Deployment configuration, hosting providers, browser extensions, and any analytics added by a deployer are outside this repository's direct control.
